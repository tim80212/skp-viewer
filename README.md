# SKP 瀏覽器（網頁）

在手機、平板上瀏覽 SketchUp 匯出的 `.glb` 瀏覽檔：旋轉、縮放、切換場景、量尺寸。只能看，不能改。

- 網址：https://tim80212.github.io/skp-viewer/
- 模型檔只在你的裝置上讀取，不會上傳到任何地方。
- 示範模型：https://tim80212.github.io/skp-viewer/?src=samples/demo_restaurant.glb

這個儲存庫只放瀏覽網頁本身（由開發用的專案自動產生，請不要直接修改）。
3D 繪圖使用 [three.js](https://threejs.org/) r160（MIT 授權，見 `lib/LICENSE`）。
